# 키보드 설정

단축키 시연이나 실시간 데모, 강의 녹화를 할 때 **지금 어떤 키를 누르고 있는지** 시청자에게 보여주면 이해가 훨씬 쉬워집니다.

미니캐스트의 키보드 표시 기능이 바로 이 역할을 합니다.

## 설정 항목 한눈에 보기

컨트롤러에서 아래 항목들을 자유롭게 조절할 수 있습니다.

| 설정 | 설명 | 기본값 |
|------|------|--------|
| 키보드 활성화 | 키 표시를 켜고 끌 수 있습니다 | 켜짐 |
| 활성 모니터 | 키 표시를 보여줄 모니터를 선택합니다 | 모니터 1 |
| 지속 시간 | 키가 화면에 유지되는 시간입니다 (ms) | 2000 |
| 폰트 크기 | 키 텍스트의 크기를 조절합니다 (px) | 16 |
| 배경 색상 | 키 박스의 배경 색을 바꿀 수 있습니다 | `#000000` |
| 배경 투명도 | 배경의 투명도를 조절합니다 (0~1) | 0.5 |
| 폰트 색상 | 글자 색을 바꿀 수 있습니다 | `#FFFFFF` |
| 표시 위치 | 화면 어디에 표시할지 정합니다 | 우측 하단 |

::: tip 조합키도 잘 표시됩니다
`Ctrl + Shift + K`처럼 여러 키를 동시에 누르면, 조합된 형태로 깔끔하게 보여줍니다.
:::

## 다중 모니터에서의 동작

키 입력은 모든 모니터 오버레이로 전달되지만, 실제로 표시되는 건 **선택한 모니터 하나**뿐입니다.

컨트롤러에서 `활성 모니터`를 바꾸면 다른 모니터로 옮길 수 있습니다.

## 알아두면 좋은 점

- 일부 Windows 환경에서는 전역 키 이벤트가 빠질 수 있어서, 보조 폴링 방식이 함께 동작합니다. 덕분에 키 입력 누락이 최소화됩니다.
- 관리자 권한으로 실행 중인 앱(예: 게임, 보안 프로그램)에서는 키 입력이 잡히지 않을 수 있습니다. 이럴 때는 미니캐스트도 관리자 권한으로 실행해 보십시오.
