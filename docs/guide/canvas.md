# 캔버스 설정 (예정)

::: warning 아직 개발 중인 기능입니다
이 페이지는 앞으로 추가될 **화면 드로잉 기능**의 계획을 정리한 것입니다.

아직 사용할 수 없으며, 개발이 완료되면 이 문서도 함께 업데이트될 예정입니다.
:::

## 어떤 기능입니까?

발표, 강의, 코드 리뷰 중에 화면 위에 **직접 그림을 그릴 수 있는** 기능을 준비하고 있습니다.

기존 커서 하이라이트나 키 표시와 충돌 없이 동작하도록 설계할 예정입니다.

## 예정된 도구들

- ✏️ **펜 / 하이라이터** — 자유롭게 그리거나 형광펜처럼 강조할 수 있습니다
- 📐 **도형** — 직선, 사각형, 원을 깔끔하게 그릴 수 있습니다
- ➡️ **화살표 / 번호 마커** — 순서를 표시하거나 특정 영역을 가리킬 수 있습니다
- 🧹 **지우개 / 실행 취소** — 잘못 그린 건 바로 되돌릴 수 있습니다
- 💾 **PNG 내보내기** — 그린 내용을 이미지로 저장할 수 있습니다

## 다중 모니터에서도 동작합니까?

네, 기존 오버레이와 마찬가지로 모니터별로 독립적인 캔버스를 제공할 계획입니다.

각 모니터의 좌표 체계에 맞춰 정확한 위치에 그릴 수 있도록 할 것입니다.
