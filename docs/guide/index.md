# 미니캐스트 시작하기

강의, 라이브 코딩, 화상회의, 스트리밍 녹화를 하다 보면 **지금 어떤 키를 눌렀는지**, **마우스가 어디에 있는지** 시청자에게 보여주고 싶을 때가 있지요.

미니캐스트는 바로 그럴 때 쓰는 앱입니다. 화면 위에 투명한 오버레이를 띄워서 키 입력과 마우스 포인터를 실시간으로 표시해 줍니다.

## 📖 가이드 목차
- [마우스 설정](./mouse.md) — 커서 하이라이트 색상·크기·투명도를 조절해 보십시오
- [키보드 설정](./keyboard.md) — 키 입력 표시 위치·폰트·지속 시간을 바꿀 수 있습니다
- [캔버스 설정(예정)](./canvas.md) — 화면 위에 직접 그리는 기능을 준비하고 있습니다

## 설치 및 실행

가장 간단한 방법은 GitHub Releases에서 `MiniCast.exe`를 받아 바로 실행하는 것입니다.

별도 설치 과정 없이 더블 클릭만 하면 됩니다.

실행하면 **메인 컨트롤러** 창과 **오버레이** 창이 함께 뜨고, 시스템 트레이에도 아이콘이 나타납니다.

소스 코드에서 직접 실행하고 싶다면 아래 명령어를 따라 해 주세요.

```bash
git clone https://github.com/andongmin94/mini-cast.git
cd mini-cast/packages
npm install
npm run tauri:dev
```

## 빌드하기

배포용 실행 파일을 만들고 싶다면 두 가지 방법이 있습니다.

- `npm run tauri:build` — 릴리즈 버전을 자동으로 맞춘 뒤 번들을 생성합니다 (권장)
- `npx tauri build` — 현재 로컬 버전 그대로 바로 번들을 만듭니다

## 기본 사용 흐름

1. **컨트롤러에서 설정 조정** — 커서 하이라이트 색상, 키보드 표시 위치 등 원하는 옵션을 골라 주세요.
2. **설정이 자동 반영** — 변경한 설정이 오버레이 창에 바로 적용됩니다.
3. **방송이나 녹화를 시작하십시오** — 오버레이가 화면 맨 위에서 키 입력과 마우스 위치를 보여줍니다.

::: tip 모든 설정은 자동 저장됩니다
앱 데이터 디렉터리의 `store.json`에 설정이 기록되므로, 다음에 실행할 때도 그대로 유지됩니다.
:::

## 다중 모니터를 쓰고 계신다면

미니캐스트는 다중 모니터 환경을 자동으로 인식합니다.

- 실행하면 모니터마다 오버레이 창이 하나씩 생성됩니다.
- 컨트롤러에서는 `모니터 1`, `모니터 2`처럼 구분해서 보여줍니다.
- 마우스 하이라이트는 포인터가 올라간 모니터에서만 표시됩니다.
- 키 입력 표시는 원하는 모니터 하나를 선택해서 띄울 수 있습니다.

## 문제가 생겼을 때

| 증상 | 이렇게 해 보십시오 |
|------|------------------|
| 키 표시가 안 나옵니다 | 컨트롤러에서 `키보드 활성화`가 켜져 있는지, `활성 모니터`가 올바른지 확인해 보십시오 |
| 커서 하이라이트가 안 보입니다 | `커서 활성화`가 켜져 있는지, 색상·투명도 설정을 확인해 보십시오 |
| 일부 앱에서 키 입력이 빠집니다 | 관리자 권한으로 실행되는 앱이나 보안 프로그램이 간섭할 수 있습니다. 미니캐스트를 관리자 권한으로 실행해 보십시오 |
| 설정이 초기화되었습니다 | `store.json` 파일이 접근 가능한 위치에 있는지 확인해 주세요 |
