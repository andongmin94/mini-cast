# 변경 이력

## 0.2.5 — 2026-11-07

`0.2.4` 다음 릴리스로 버전 표기를 정리했습니다. 개발 중 나뉘어 기록했던 판서 기능과 안정화 작업을 이 버전으로 통합합니다. 세부 구현 이력은 Git 기록에서 확인할 수 있습니다.

### 판서와 편집

- 펜·형광펜·객체 지우개, 직선·화살표·사각형·타원과 내부 채우기.
- 한글·여러 줄 텍스트 작성과 기존 텍스트 재편집.
- 단일·그룹 선택, 이동·크기 조절·회전·반전·삭제와 시간순 Undo/Redo.
- 다중 모니터 판서와 모니터별 화이트보드·블랙보드.
- 영구 문서와 분리된 레이저 포인터·사라지는 잉크.
- 편집 가능한 `.minicast` 파일 저장·열기, 투명 PNG 저장·이미지 클립보드 복사.

### 안정성 및 유지보수

- 메인 프로세스가 문서·이력을 소유하며 revision 기반 변경분 동기화와 부분 Canvas 재그리기를 사용합니다.
- 저장 중 종료를 보류하고, 저장한 내용과 다른 판서는 정상 종료 전에 확인합니다.
- 텍스트 편집·네이티브 파일 작업·모니터 재구성 중 충돌하는 입력을 제어합니다.
- 화면 크기 변경과 텍스트 이동으로 객체의 허용 범위를 벗어나는 변경을 원자적으로 거부합니다.
- 판서 도구와 실행 취소 조작의 접근성을 개선하고 슬라이더 이름을 보조 기술에 연결합니다.
- 레이저 포인터의 네이티브 좌표를 화면 배율에 맞게 변환합니다.
- 빌드 전용 의존성을 개발 의존성으로 옮기고 보안 수정이 적용된 의존성으로 갱신합니다.
- 통합 검증 모듈은 검사 모드에서만 불러옵니다.

### 배포

- Windows x64 MSI·포터블 EXE와 소스 SHA·파일 해시를 포함한 배포 ZIP을 제공합니다.
- 기존 Windows Verify를 통과한 수동 실행에서만 릴리스를 게시할 수 있습니다.
- 자동 저장·강제 종료 후 복구·배경 화면 캡처는 지원하지 않습니다. 물리 GPU·혼합 DPI 모니터·펜 드라이버·한글 IME의 실물 검증은 별도입니다.
