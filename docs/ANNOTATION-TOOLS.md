# 화면 판서

현재 문서 기준은 0.11.0입니다. 판서 문서는 앱 실행 중에만 보관하고, 도구·표시 설정만 디스크에 저장합니다.

## 그리기

펜·형광펜·요소 지우개와 직선·화살표·사각형·타원을 지원합니다. 도형은 드래그 중 미리보기를 표시하고 버튼을 놓으면 한 객체로 확정합니다. 사실상 움직이지 않은 클릭은 객체나 Undo 이력을 만들지 않습니다.

- 직선·화살표는 Shift로 방향을 45도 간격에 고정합니다.
- 사각형·타원은 Shift로 정사각형·원을 만듭니다.
- 도형은 펜 색상과 굵기를 사용합니다. 화살표의 몸통과 머리는 하나의 객체입니다.
- 요소 지우개는 닿은 객체 전체를 지웁니다. 빈 사각형·타원은 외곽선만, 채워진 도형은 내부도 검사합니다.

판서 중에는 일반 마우스 하이라이트와 클릭 효과가 숨겨집니다. Windows의 빈 투명 영역에서 입력이 누락되지 않도록 판서 모드에만 약 1/255의 최소 알파 배경을 적용합니다. 이 입력 배경은 문서와 Canvas 픽셀에 포함하지 않고 조작 모드에서 제거합니다.

## 텍스트 배치

텍스트 도구를 선택하고 컨트롤러에서 내용을 입력합니다. ‘화면에 배치’ 또는 Ctrl+Enter로 준비한 뒤 화면을 클릭합니다. 같은 준비된 내용을 여러 번 배치할 수 있습니다.

글자 크기는 12–96px이며, 문자열은 2,000 UTF-16 코드 단위와 20줄 이내입니다. Enter는 줄바꿈이고 CRLF·탭은 줄바꿈·공백으로 정규화합니다. HTML은 해석하지 않습니다. 한글 조합 중 Enter는 배치를 확정하지 않습니다. 준비된 텍스트와 작성 중 초안은 디스크에 저장하지 않습니다.

텍스트 입력란에 포커스가 있으면 판서의 Undo/Redo·Escape 전역 단축키를 해제합니다. Ctrl+Z는 입력란의 문자를 되돌리고, 입력 내용은 일반 키 시각화에 보내지 않습니다. 입력란에서 조합 중이 아닌 Escape는 조작 모드로 돌아갑니다.

번들 Pretendard의 로딩이 끝난 뒤 Canvas로 글자 경계를 측정합니다. 텍스트의 지우기·선택은 개별 글자가 아닌 실제로 변환된 레이아웃 사각형을 대상으로 합니다. 회전한 글자의 축 정렬 경계 상자에서 비어 있는 모서리는 선택·지우개에 반응하지 않습니다.

## 기존 텍스트 수정 (0.8.0)

선택 도구로 텍스트 하나를 고른 뒤 하단 ‘텍스트 수정’을 누릅니다. 기존 컨트롤러의 입력란에서 내용과 기본 글자 크기를 고치고 ‘수정 적용’ 또는 Ctrl+Enter로 저장합니다. 회전·기울어짐·확대 배율·위치·색상·객체 ID·겹침 순서는 유지하며 글자 배치 영역만 새 내용으로 다시 측정합니다. 글자 크기 변경은 기존 확대 배율에 추가로 적용됩니다.

입력란 Ctrl+Z는 입력 중 문자에만 적용하고, 저장된 내용 변경 전체는 문서 Undo 한 번으로 복원합니다. 변화 없는 저장은 문서 revision이나 Redo를 바꾸지 않습니다. 빈 내용은 저장하지 않으며 객체 제거에는 선택 삭제를 사용합니다. 입력 중 Escape와 ‘수정 취소’는 초안을 버리고 선택 모드를 유지합니다.

다른 편집으로 문서 revision이 바뀌면 오래된 저장을 거부하고 초안을 유지해 확인할 수 있게 합니다. 이 경우 취소 후 최신 객체를 다시 선택해야 합니다. 용량이나 좌표 한도를 넘는 변경은 기존 객체를 수정하지 않습니다. 도구 전환·컨트롤러 숨김/재로딩·화면 재구성은 미저장 편집을 취소합니다. 초안과 편집 세션은 디스크에 저장하지 않습니다.

## 선택·이동·삭제

컨트롤러의 ‘선택’ 도구로 객체를 클릭합니다. 겹친 위치에서는 맨 위 객체를 고르며, 빈 사각형·타원은 외곽선을 클릭해야 합니다. Shift+클릭으로 같은 모니터의 객체를 선택에 추가하거나 제외합니다. 선택한 객체를 드래그하면 그룹이 함께 움직입니다. 빈 곳 클릭이나 ‘선택 해제’는 선택을 비웁니다.

하단의 ‘선택 삭제’는 선택된 객체만 지웁니다. Delete 키는 전역 등록하지 않습니다. 선택 자체는 임시 UI이며 도구 변경·renderer 재로딩에서 초기화됩니다. 확정된 문서는 유지합니다.

## 크기 조절

네 모서리의 흰색 핸들을 드래그합니다. Shift를 누르면 가로·세로 비율을 유지하고, 여러 객체도 함께 조절합니다. 반대 모서리를 기준으로 드래그 시작 문서에서 계산하므로 이전 프레임의 반올림을 누적하지 않습니다.

펜·형광펜·도형의 선 굵기는 가로·세로 배율의 기하평균만큼 바뀝니다. 선 굵기는 여전히 단일 값이며 비틀린 펜촉으로 변환하지 않습니다. 텍스트는 문자열과 기본 글자 크기를 유지하고 레이아웃을 변형합니다. 반대 모서리를 넘어도 뒤집거나 0 크기로 만들지 않고 최소 범위에서 멈춥니다. 좌표·굵기·텍스트 프레임의 허용 범위를 넘으면 그룹 전체를 거부합니다.

12px 크기 조절 입력 대상은 점·가는 선에서도 겹치지 않게 배치하고 화면 가장자리에서는 안쪽으로 옮깁니다. 이 UI 보정은 실제 변형 기준점을 바꾸지 않습니다.

## 회전

선택 테두리 바깥의 원형 회전 핸들을 드래그합니다. Shift를 누르면 드래그 시작 방향으로부터 15도 간격에 고정합니다. 그룹은 선택 객체 전체의 중심을 기준으로 함께 회전합니다. 핸들 가장자리를 눌러도 처음부터 방향이 튀지 않으며, 회전 중심 바로 근처에서는 마지막 유효 각도를 유지합니다.

회전만으로 색상·투명도·선 굵기·객체 ID·겹침 순서·텍스트 내용은 바뀌지 않습니다. 회전 뒤의 크기 조절은 화면 가로·세로 축을 기준으로 하는 affine 변형입니다. 비균등 확대에서는 사각형이 평행사변형이 될 수 있으며, 이를 축 정렬 사각형으로 강제 변환하지 않습니다. 타원은 회전·비균등 확대 뒤에도 해석적인 곡선으로 렌더링합니다.

## 좌우·상하 반전 (0.9.0)

선택 도구로 하나 이상의 객체를 고르고 하단 ‘좌우 반전’ 또는 ‘상하 반전’을 누릅니다. 좌우 반전은 선택 영역 중심의 세로선을, 상하 반전은 가로선을 기준으로 반사합니다. 여러 객체는 각자의 중심이 아니라 그룹 전체의 공통 중심을 사용합니다. 기준선은 실제 문서 경계로 계산하며 화면 안으로 보정된 핸들 위치는 사용하지 않습니다.

문자도 거울에 비친 모양으로 반전합니다. 문자열 자체를 뒤집거나 다른 글자로 바꾸지 않습니다. 색상·선 굵기·투명도·ID·겹침 순서·기존 회전과 기울어짐은 반사 변환 외에는 바꾸지 않습니다. 반전한 텍스트의 내용 수정과 도형의 이동·회전·크기 조절도 계속 가능합니다.

한 번의 반전은 그룹 전체에 대한 Undo 한 번입니다. 좌표가 전혀 바뀌지 않는 점·선 조작은 이력과 Redo를 바꾸지 않습니다. 최신 revision과 대상 객체를 확인한 뒤 그룹 전체를 한 번에 적용하며, 범위를 벗어나거나 오래된 요청은 일부만 적용하지 않습니다. 선택하지 않았거나 다른 편집을 적용 중이면 버튼을 비활성화합니다. 좁은 화면에서는 선택 툴바를 여러 줄로 배치합니다.

## 사각형·타원 채우기 (0.10.0)

컨트롤러에서 ‘새 사각형·타원 내부 채우기’를 켜고 채우기 색상을 정한 뒤 그립니다. 윤곽선 색상·굵기와 내부 색상은 독립적입니다. 기본값은 채우기 없음이며, 설정 변경은 이미 그린 객체를 바꾸지 않습니다. 이번 채우기는 불투명 단색이며 그라데이션·별도 채우기 투명도·열린 선 채우기는 지원하지 않습니다.

기존 도형은 선택 후 하단 ‘채우기 적용’ 또는 ‘채우기 제거’를 사용합니다. 사각형·타원만으로 구성된 그룹에 한 번에 적용하고, 펜·텍스트·직선 등 다른 객체가 포함되면 버튼을 비활성화합니다. 전체 그룹이 하나의 Undo 이력이며 같은 색상을 다시 적용하거나 이미 빈 도형의 채우기를 제거하는 조작은 revision·Redo를 바꾸지 않습니다.

채워진 도형은 내부에서도 선택·요소 지우개를 사용할 수 있습니다. 빈 도형은 윤곽선만 대상으로 하며, 타원의 빈 모서리나 회전·기울어짐 뒤의 바깥 경계 상자는 채워진 내부로 취급하지 않습니다. 이동·크기 조절·회전·반전·viewport 변경·동기화·Undo/Redo에서 채우기 속성을 보존합니다.

## 이력·취소·동기화

이동·크기 조절·회전·선택 삭제 각각 한 번을 그룹 전체에 대한 Undo 한 번으로 처리합니다. 클릭이나 변화 없는 조작은 이력과 Redo를 바꾸지 않습니다. 조작 중 Ctrl+Z는 진행 중 미리보기만 취소하고, Escape는 조작 모드로 돌아갑니다. 재로딩·도구 변경은 미완성 작업을 폐기합니다.

main process의 모니터별 문서와 전역 시간순 Undo/Redo가 권위 상태입니다. 편집은 기준 revision을 포함하고, 다른 편집이나 화면 재설정으로 revision이 바뀌면 오래된 요청을 그룹 단위로 거부합니다. 초기 연결·복구에는 전체 문서를, 일반 편집에는 변경분을 전달합니다.

자유곡선은 점 목록, 직선·화살표는 두 끝점, 사각형·타원·텍스트는 원점과 두 축 끝점으로 저장합니다. 별도의 회전 전용 이력이나 래스터 객체를 만들지 않습니다. 기존 두 점 박스와 텍스트 scaleX/scaleY 계약은 제거했으며 renderer·preload·main을 함께 빌드해야 합니다. 타원은 지우개 판정에서만 보수적인 0.125 CSS px 오차 범위로 선분화합니다.

## 검증과 범위

단위 검사는 기하·불변성·원자적 거부·전역 이력·viewport 변형·변경분 복구를 검사합니다. `rendering-smoke.ts`는 실제 Chromium에서 부분 재그리기와 전체 재그리기를 픽셀 단위로 비교합니다. `resize-smoke.ts`와 `rotation-smoke.ts`는 Windows 입력으로 핸들·Shift 그룹 조작·취소·오래된 revision·드래그 중 재로딩을 검사합니다. 성공 여부는 해당 실행의 로그를 기준으로 판단합니다. 검증 워크플로는 수동 실행만 허용합니다.

실물 GPU·펜 드라이버·혼합 DPI 모니터·물리 한글 IME는 별도 검증 대상입니다. 캡처 및 판서 파일 저장은 아직 지원하지 않습니다.

## 레이저·사라지는 잉크 (0.11.0)

레이저는 포인터를 따라가는 빨간 점이며 클릭·드래그해도 선이나 문서 객체를 남기지 않습니다. 사라지는 잉크는 현재 펜 색상·굵기로 그리며, 각 획은 버튼을 놓은 뒤 2초 동안 유지한 후 0.7초 동안 사라집니다. 누르고 있는 획은 유지됩니다. 두 도구 모두 아래 프로그램의 클릭을 차단하며 Escape로 조작 모드에 복귀합니다. 이번 레이저는 궤적을 남기는 도구가 아닙니다.

임시 표시 모드의 Ctrl+Z는 진행 중 입력만 취소합니다. 완료된 임시 획은 Undo/Redo에 들어가지 않고 Redo는 비활성화됩니다. ‘임시 지우기’는 모든 모니터의 임시 표시만 지우며 기존 판서와 문서 Redo는 보존합니다. 일반 판서 모드로 돌아가면 기존 Undo/Redo를 계속 사용할 수 있습니다.

임시 좌표는 renderer에만 존재하며 IPC 문서·선택·지우개·설정 파일에 넣지 않습니다. 도구 전환·재로딩·화면 크기 변경·숨김 시 임시 표시를 폐기하고, 모니터를 벗어난 진행 중 입력은 취소합니다. 프레임 수가 아니라 단조 시계의 경과 시간으로 소멸시켜 애니메이션 재개 때 만료된 획을 제거합니다. 표시할 애니메이션이 없으면 RAF 반복을 멈춥니다.

한 화면에 최대 32개의 임시 획과 16,384포인트를 유지합니다. 용량이 차면 오래된 완료 임시 획만 먼저 폐기합니다. 한 획은 4,096포인트에서 마무리하고 사용자에게 안내합니다. 영구 문서에는 이 정책을 적용하지 않습니다.
