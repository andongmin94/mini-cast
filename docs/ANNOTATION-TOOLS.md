# 도형 및 텍스트 판서

## 추가 도구

직선, 화살표, 사각형, 타원은 화면에서 드래그해 배치합니다. 드래그하는 동안 미리보기를 표시하고 버튼을 놓으면 한 개의 객체로 확정합니다. 빈 사각형·타원의 내부는 지우개에 반응하지 않고 외곽선만 검사합니다. 화살표는 몸통과 머리가 한 객체입니다.

- 직선·화살표: Shift를 누르면 방향을 45도 간격으로 고정합니다.
- 사각형·타원: Shift를 누르면 정사각형·원으로 만듭니다.
- 도형의 색상과 두께는 기존 펜 설정을 함께 사용합니다.
- 사실상 움직이지 않은 도형 클릭은 새 객체나 Undo 이력을 만들지 않습니다.
- 새 도구는 컨트롤러 버튼으로 선택합니다. 기존 전역 단축키는 변경하지 않습니다.

## 텍스트

텍스트 도구를 선택하고 컨트롤러에서 내용을 입력합니다. '화면에 배치' 또는 Ctrl+Enter로 준비한 뒤 화면의 원하는 위치를 클릭합니다. 같은 준비된 내용을 여러 번 배치할 수 있습니다.

글자 크기는 12–96px입니다. 문자열은 2,000 UTF-16 코드 단위, 20줄 이내이며 Enter는 줄바꿈입니다. CRLF와 탭은 각각 줄바꿈과 공백으로 정규화합니다. HTML 태그는 해석하지 않고 문자 그대로 그립니다. 한글 조합 중 Enter로 배치를 확정하지 않습니다.

편집 포커스를 가진 동안 판서의 Undo/Redo·Escape 전역 단축키를 해제합니다. 따라서 Ctrl+Z는 입력란 편집에 사용되고 일반 키 시각화에도 입력 내용이 전송되지 않습니다. 입력란에서 조합 중이 아닌 Escape는 클릭 통과로 돌아갑니다. 준비된 텍스트와 작성 중 초안은 디스크 설정에 저장하지 않습니다.

폰트는 기존 앱에 포함된 Pretendard를 사용합니다. 로딩이 끝나기 전에는 새 텍스트를 배치하지 않으며, 표시 크기와 실제 글자 경계를 Canvas 측정값으로 계산합니다. 지우개는 글자 하나가 아니라 텍스트 레이아웃 영역 전체를 한 객체로 취급합니다.

## 기존 기능과의 연결

문서 항목은 `AnnotationElement`로 통일합니다. 자유곡선, 도형, 텍스트 모두 같은 모니터별 문서와 전역 Undo/Redo, 변경분 IPC, revision 복구, 부분 재그리기를 사용합니다. 도형은 두 앵커만 저장하며 타원을 저장용 자유곡선으로 변환하지 않습니다. 지우개에 한해 타원을 보수적인 0.125 CSS px 오차 한도로 선분화합니다.

텍스트의 글자 수는 문서 및 이력의 기존 저장량 예산에 포함됩니다. 화면 크기가 바뀌면 위치와 텍스트 배율도 문서·Undo/Redo 이력에서 함께 변환됩니다. 형광펜의 기존 합성 순서는 유지됩니다.

기존 스트로크 전용 IPC 이름은 제거하고 `annotation-add-element`, `annotation-remove-elements`로 통일했습니다. renderer·preload·main과 테스트는 함께 교체해야 하며, 구버전과 신버전을 혼합하지 않습니다. 판서 문서는 기존과 같이 앱 실행 중에만 보관됩니다.

## 아직 포함하지 않은 기능

객체 선택·이동·선택 삭제는 지원합니다. 크기 변경을 지원합니다. 회전·기존 텍스트 재편집은 아직 지원하지 않습니다. 채우기, 레이저, 캡처, 파일 저장도 추가하지 않습니다.

## 검증

`tests/unit/annotation/shapes-and-text.test.mjs`는 도형·텍스트 유효성, 지우기, 텍스트 예산, 불변성, viewport 변환과 혼합 문서 Undo/Redo·delta 동기화를 검사합니다. `src/electron/testing/rendering-smoke.ts`는 Chromium Canvas의 부분 재그리기를 전체 재그리기와 픽셀 단위로 비교합니다.

Windows 통합 시나리오는 실제 컨트롤러 도구 버튼·드래그, Undo/Redo·지우개, 입력란 Ctrl+Z와 텍스트 reload를 검사하도록 추가했습니다. 시나리오가 소스에 존재하는 것과 해당 환경에서 실행을 통과한 것은 별개입니다. 적용 후 `npm run check` 및 기존 수동 Verify로 최종 확인해야 합니다. Actions 자동 실행 조건은 변경하지 않습니다.

판서 모드에서는 Windows가 빈 투명 영역에도 입력을 전달하도록 1/255에 가까운 최소 알파 배경을 사용합니다. 이 배경은 판서 문서나 Canvas 픽셀에 저장되지 않으며 조작 모드에서는 제거됩니다.

## 선택·이동·삭제 (0.5.0)

컨트롤러의 ‘선택’ 도구를 누른 뒤 객체를 클릭합니다. 겹친 객체는 맨 위의 선·글자부터 선택하며 빈 사각형·타원의 내부는 선택하지 않습니다. Shift+클릭으로 같은 모니터 안의 객체를 추가하거나 제외하고, 선택한 객체를 드래그하면 선택한 그룹이 함께 이동합니다. 빈 곳을 클릭하면 선택을 해제합니다.

선택 모드 하단의 ‘선택 삭제’는 선택한 객체만 삭제합니다. Delete 키는 등록하지 않으므로 다른 프로그램의 삭제 단축키를 가로채지 않습니다. 기존 Ctrl+Z/다시 실행은 이동과 삭제에도 적용합니다. 단순 클릭·선택 해제·미세한 드래그는 이력을 만들지 않습니다. 이동 중 Ctrl+Z는 진행 중 이동만 취소하고, Escape는 클릭 통과로 돌아갑니다.

선택은 모니터별 임시 상태입니다. 도구 전환이나 renderer 재로딩에서는 선택을 초기화하고 확정된 문서는 유지합니다. 이동은 원래 ID·순서·색상·굵기·텍스트 내용을 그대로 보존합니다. 이동 한 번은 하나의 전역 Undo 항목이며, 다른 편집이나 화면 재설정으로 문서 revision이 바뀌었다면 오래된 선택 편집은 거부합니다.

검증 코드는 실제 Windows 클릭·드래그·Ctrl+Z·선택 삭제 버튼·renderer reload 및 stale revision 거부를 확인합니다. 각 실행의 성공 여부는 해당 진단 로그를 기준으로 판단합니다.


## 선택 크기 조절 (0.6.0)

선택한 객체의 네 모서리에 나타나는 흰색 핸들을 드래그합니다. Shift를 누르고 드래그하면 가로·세로 비율을 유지합니다. Shift+클릭으로 고른 여러 객체도 한 그룹으로 크기를 바꿉니다. 반대 모서리를 기준으로 원래 문서의 좌표를 변환하고, 이전 프레임의 미리보기를 다시 확대하지 않습니다.

펜·형광펜·도형은 좌표와 함께 선 굵기를 가로 배율과 세로 배율의 기하평균만큼 바꿉니다. 비균등 확대에서도 선 굵기는 단일 값이며 비틀린 펜촉으로 변환하지 않습니다. 텍스트는 내용·기본 글자 크기를 유지하고 레이아웃의 가로·세로 배율을 바꿉니다. 모서리를 반대편 너머로 끌어도 뒤집거나 0 크기로 만들지 않습니다. 최소 범위에서 멈추며, 좌표·선 굵기·텍스트 배율의 허용 한도를 넘으면 전체 조절을 취소하고 알립니다.

크기 조절 한 번은 그룹 전체에 대해 한 번의 Undo입니다. 단순 핸들 클릭은 이력이나 Redo를 바꾸지 않습니다. 조절 중 Ctrl+Z는 현재 미리보기만 취소하고, Escape는 클릭 통과로 돌아갑니다. 다른 편집이나 화면 재설정으로 revision이 바뀌면 오래된 크기 조절은 거부합니다. 재로딩 중인 미완성 조절과 선택 핸들은 버리고 확정된 문서는 유지합니다.

`tests/unit/annotation/resize.test.mjs`는 네 모서리·비율·최소 크기·원자적 거부·문서 이력·viewport·동기화를 검사합니다. Windows 검증은 실제 핸들 드래그와 Shift 그룹 조절, Undo/Redo, 미리보기의 픽셀 복원, 오래된 revision, 드래그 중 reload와 Escape를 검사합니다. 회전·반전·기존 텍스트 내용 편집은 이번 범위가 아닙니다.
