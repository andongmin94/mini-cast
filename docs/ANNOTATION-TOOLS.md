# 화면 판서

현재 문서 기준은 0.14.2입니다. 실행 중 판서와 Undo/Redo는 메인 프로세스가 관리합니다. 설정은 자동 저장하고, 확정 판서는 사용자가 `.minicast` 파일로 저장·열기하거나 투명 PNG로 내보낼 수 있습니다. 앱 종료 시 판서를 자동 저장하거나 다음 실행에서 자동 복원하지는 않습니다.

## 그리기

펜·형광펜·요소 지우개와 직선·화살표·사각형·타원을 지원합니다. 도형은 드래그 중 미리보기를 표시하고 버튼을 놓으면 한 객체로 확정합니다. 사실상 움직이지 않은 클릭은 객체나 Undo 이력을 만들지 않습니다.

- 직선·화살표는 Shift로 방향을 45도 간격에 고정합니다.
- 사각형·타원은 Shift로 정사각형·원을 만듭니다.
- 도형은 펜 색상과 굵기를 사용합니다. 화살표의 몸통과 머리는 하나의 객체입니다.
- 요소 지우개는 닿은 객체 전체를 지웁니다. 빈 사각형·타원은 외곽선만, 채워진 도형은 내부도 검사합니다.

판서 중에는 일반 마우스 하이라이트와 클릭 효과가 숨겨집니다. Windows의 빈 투명 영역에서 입력이 누락되지 않도록 판서 모드에만 약 1/255의 최소 알파 배경을 적용합니다. 이 입력 배경은 문서와 Canvas 픽셀에 포함하지 않고 조작 모드에서 제거합니다. 키 입력 표시는 판서 중에도 유지하며 MiniCast 판서 단축키는 표시하지 않습니다.

## 텍스트 배치

텍스트 도구를 선택하고 컨트롤러에서 내용을 입력합니다. ‘화면에 배치’ 또는 Ctrl+Enter로 준비한 뒤 화면을 클릭합니다. 같은 준비된 내용을 여러 번 배치할 수 있습니다.

글자 크기는 12–96px이며, 문자열은 2,000 UTF-16 코드 단위와 20줄 이내입니다. Enter는 줄바꿈이고 CRLF·탭은 줄바꿈·공백으로 정규화합니다. HTML은 해석하지 않습니다. 한글 조합 중 Enter는 배치를 확정하지 않습니다. 배치 전 초안은 판서 파일에 포함하지 않습니다.

텍스트 입력란에 포커스가 있으면 판서의 Undo/Redo·Escape 전역 단축키를 해제합니다. Ctrl+Z는 입력란의 문자를 되돌리고, 입력 내용은 일반 키 시각화에 보내지 않습니다. 새 텍스트 입력란에서 조합 중이 아닌 Escape는 조작 모드로 돌아갑니다.

번들 Pretendard의 로딩이 끝난 뒤 Canvas로 글자 경계를 측정합니다. 텍스트의 지우기·선택은 개별 글자가 아닌 실제로 변환된 레이아웃 사각형을 대상으로 합니다. 회전한 글자의 축 정렬 경계 상자에서 비어 있는 모서리는 선택·지우개에 반응하지 않습니다.

## 기존 텍스트 수정

선택 도구로 텍스트 하나를 고른 뒤 하단 ‘텍스트 수정’을 누릅니다. 기존 컨트롤러의 입력란에서 내용과 기본 글자 크기를 고치고 ‘수정 적용’ 또는 Ctrl+Enter로 저장합니다. 회전·기울어짐·확대 배율·위치·색상·객체 ID·겹침 순서는 유지하며 글자 배치 영역만 새 내용으로 다시 측정합니다. 글자 크기 변경은 기존 확대 배율에 추가로 적용됩니다.

입력란 Ctrl+Z는 입력 중 문자에만 적용하고, 저장된 내용 변경 전체는 문서 Undo 한 번으로 복원합니다. 변화 없는 저장은 문서 revision이나 Redo를 바꾸지 않습니다. 빈 내용은 저장하지 않으며 객체 제거에는 선택 삭제를 사용합니다. 기존 텍스트 수정 중 Escape와 ‘수정 취소’는 초안을 버리고 선택 모드를 유지합니다.

다른 편집으로 문서 revision이 바뀌면 오래된 저장을 거부하고 초안을 유지해 확인할 수 있게 합니다. 이 경우 취소 후 최신 객체를 다시 선택해야 합니다. 용량이나 좌표 한도를 넘는 변경은 기존 객체를 수정하지 않습니다. 도구 전환·컨트롤러 숨김/재로딩·화면 재구성은 미저장 편집을 취소합니다. 초안과 편집 세션은 디스크에 저장하지 않습니다.

## 선택·이동·삭제

컨트롤러의 ‘선택’ 도구로 객체를 클릭합니다. 겹친 위치에서는 맨 위 객체를 고르며, 빈 사각형·타원은 외곽선을 클릭해야 합니다. Shift+클릭으로 같은 모니터의 객체를 선택에 추가하거나 제외합니다. 선택한 객체를 드래그하면 그룹이 함께 움직입니다. 빈 곳 클릭이나 ‘선택 해제’는 선택을 비웁니다.

하단의 ‘선택 삭제’는 선택된 객체만 지웁니다. Delete 키는 전역 등록하지 않습니다. 선택 자체는 임시 UI이며 도구 변경·renderer 재로딩에서 초기화됩니다. 확정된 문서는 유지합니다.

## 크기 조절

네 모서리의 흰색 핸들을 드래그합니다. Shift를 누르면 가로·세로 비율을 유지하고, 여러 객체도 함께 조절합니다. 반대 모서리를 기준으로 드래그 시작 문서에서 계산하므로 이전 프레임의 반올림을 누적하지 않습니다.

펜·형광펜·도형의 선 굵기는 가로·세로 배율의 기하평균만큼 바뀝니다. 선 굵기는 여전히 단일 값이며 비틀린 펜촉으로 변환하지 않습니다. 텍스트는 문자열과 기본 글자 크기를 유지하고 레이아웃을 변형합니다. 반대 모서리를 넘어도 뒤집거나 0 크기로 만들지 않고 최소 범위에서 멈춥니다. 좌표·굵기·텍스트 프레임의 허용 범위를 넘으면 그룹 전체를 거부합니다.

12px 크기 조절 입력 대상은 점·가는 선에서도 겹치지 않게 배치하고 화면 가장자리에서는 안쪽으로 옮깁니다. 이 UI 보정은 실제 변형 기준점을 바꾸지 않습니다.

## 회전

선택 테두리 바깥의 원형 회전 핸들을 드래그합니다. Shift를 누르면 드래그 시작 방향으로부터 15도 간격에 고정합니다. 그룹은 선택 객체 전체의 중심을 기준으로 함께 회전합니다. 핸들 가장자리를 눌러도 처음부터 방향이 튀지 않으며, 회전 중심 바로 근처에서는 마지막 유효 각도를 유지합니다.

회전만으로 색상·투명도·선 굵기·객체 ID·겹침 순서·텍스트 내용은 바뀌지 않습니다. 회전 뒤의 크기 조절은 화면 가로·세로 축을 기준으로 하는 affine 변형입니다. 비균등 확대에서는 사각형이 평행사변형이 될 수 있으며, 이를 축 정렬 사각형으로 강제 변환하지 않습니다. 타원은 회전·비균등 확대 뒤에도 해석적인 곡선으로 렌더링합니다.

## 좌우·상하 반전

선택 도구로 하나 이상의 객체를 고르고 하단 ‘좌우 반전’ 또는 ‘상하 반전’을 누릅니다. 좌우 반전은 선택 영역 중심의 세로선을, 상하 반전은 가로선을 기준으로 반사합니다. 여러 객체는 각자의 중심이 아니라 그룹 전체의 공통 중심을 사용합니다. 기준선은 실제 문서 경계로 계산하며 화면 안으로 보정된 핸들 위치는 사용하지 않습니다.

문자도 거울에 비친 모양으로 반전합니다. 문자열 자체를 뒤집거나 다른 글자로 바꾸지 않습니다. 색상·선 굵기·투명도·ID·겹침 순서·기존 회전과 기울어짐은 반사 변환 외에는 바꾸지 않습니다. 반전한 텍스트의 내용 수정과 도형의 이동·회전·크기 조절도 계속 가능합니다.

한 번의 반전은 그룹 전체에 대한 Undo 한 번입니다. 좌표가 전혀 바뀌지 않는 점·선 조작은 이력과 Redo를 바꾸지 않습니다. 최신 revision과 대상 객체를 확인한 뒤 그룹 전체를 한 번에 적용하며, 범위를 벗어나거나 오래된 요청은 일부만 적용하지 않습니다. 선택하지 않았거나 다른 편집을 적용 중이면 버튼을 비활성화합니다. 좁은 화면에서는 선택 툴바를 여러 줄로 배치합니다.

## 사각형·타원 채우기

컨트롤러에서 ‘새 사각형·타원 내부 채우기’를 켜고 채우기 색상을 정한 뒤 그립니다. 윤곽선 색상·굵기와 내부 색상은 독립적입니다. 기본값은 채우기 없음이며, 설정 변경은 이미 그린 객체를 바꾸지 않습니다. 채우기는 불투명 단색이며 그라데이션·별도 채우기 투명도·열린 선 채우기는 지원하지 않습니다.

기존 도형은 선택 후 하단 ‘채우기 적용’ 또는 ‘채우기 제거’를 사용합니다. 사각형·타원만으로 구성된 그룹에 한 번에 적용하고, 펜·텍스트·직선 등 다른 객체가 포함되면 버튼을 비활성화합니다. 전체 그룹이 하나의 Undo 이력이며 같은 색상을 다시 적용하거나 이미 빈 도형의 채우기를 제거하는 조작은 revision·Redo를 바꾸지 않습니다.

채워진 도형은 내부에서도 선택·요소 지우개를 사용할 수 있습니다. 빈 도형은 윤곽선만 대상으로 하며, 타원의 빈 모서리나 회전·기울어짐 뒤의 바깥 경계 상자는 채워진 내부로 취급하지 않습니다. 이동·크기 조절·회전·반전·viewport 변경·동기화·Undo/Redo에서 채우기 속성을 보존합니다.

## 레이저·사라지는 잉크

레이저는 포인터를 따라가는 빨간 점이며 클릭·드래그해도 선이나 문서 객체를 남기지 않습니다. 사라지는 잉크는 현재 펜 색상·굵기로 그리며, 각 획은 버튼을 놓은 뒤 2초 동안 유지한 후 0.7초 동안 사라집니다. 누르고 있는 획은 유지됩니다. 두 도구 모두 아래 프로그램의 클릭을 차단하며 Escape로 조작 모드에 복귀합니다. 레이저 궤적은 남기지 않습니다.

임시 표시 모드의 Ctrl+Z는 진행 중 입력만 취소합니다. 완료된 임시 획은 Undo/Redo에 들어가지 않고 Redo는 비활성화됩니다. ‘임시 지우기’는 모든 모니터의 임시 표시만 지우며 기존 판서와 문서 Redo는 보존합니다. 일반 판서 모드로 돌아가면 기존 Undo/Redo를 계속 사용할 수 있습니다.

임시 좌표는 renderer에만 존재하며 IPC 문서·선택·지우개·설정 파일·판서 파일에 넣지 않습니다. 도구 전환·재로딩·화면 크기 변경·숨김 시 임시 표시를 폐기하고, 모니터를 벗어난 진행 중 입력은 취소합니다. 프레임 수가 아니라 단조 시계의 경과 시간으로 소멸시켜 애니메이션 재개 때 만료된 획을 제거합니다. 표시할 애니메이션이 없으면 RAF 반복을 멈춥니다.

한 화면에 최대 32개의 임시 획과 16,384포인트를 유지합니다. 용량이 차면 오래된 완료 임시 획만 먼저 폐기합니다. 한 획은 4,096포인트에서 마무리하고 사용자에게 안내합니다. 영구 문서에는 이 정책을 적용하지 않습니다.

## 투명 PNG 저장·클립보드 복사

판서 탭의 ‘판서 이미지 내보내기’에서 대상 모니터를 선택하고 ‘PNG 저장’ 또는 ‘이미지 복사’를 누릅니다. 화면 전체 크기에 맞는 투명 PNG이며, 해당 물리 모니터의 배율을 사용합니다. Chromium 확대율과는 독립적입니다. 한 변 8,192px, 총 16,777,216픽셀을 넘으면 오류를 안내하고 임의 축소하지 않습니다.

요청 시점의 확정 문서를 별도 Canvas에서 원래 순서로 그립니다. 배경 화면·컨트롤러·선택 테두리·진행 중 미리보기·레이저·사라지는 잉크는 포함하지 않습니다. 저장 중 문서가 변경돼도 이미 요청한 이미지에는 섞이지 않습니다. 내보내기는 문서·Undo/Redo를 수정하지 않습니다.

PNG 저장은 조작 모드로 전환하고 네이티브 저장 창을 엽니다. 취소해도 문서와 기존 파일은 유지됩니다. 파일 이름은 .png 확장자를 사용합니다. 기록은 기존 원자적 파일 저장 라이브러리를 사용하며, 승인된 쓰기가 시작된 후에는 정상 종료를 잠시 지연해 쓰기의 성공 또는 실패를 기다립니다. 이미지 복사는 Electron 44의 비동기 ClipboardItem API로 시스템 이미지 클립보드를 대체하며 완료 후에만 성공을 표시합니다. 붙여넣는 프로그램의 투명 배경 지원 여부에 따라 표현이 달라질 수 있습니다.

빈 문서·연결 해제·텍스트 편집 중 요청·중복 요청·렌더링 실패는 별도 안내합니다. renderer에는 파일 경로나 범용 클립보드 API를 노출하지 않습니다. PNG 응답은 요청한 창·일회용 토큰·해상도·용량을 검사한 뒤 네이티브 디코더로 확인합니다. 텍스트 폰트 로드를 기다리며, 창 재로딩과 15초 렌더링 제한을 처리합니다. 저장 대화상자에서 사용자가 선택하는 시간에는 자동 취소 제한을 두지 않습니다.

PNG는 래스터 이미지이며 그 자체를 다시 편집 가능한 판서로 여는 기능은 없습니다. 편집할 객체를 보관할 때는 아래의 .minicast 파일을 사용합니다. 배경 화면 캡처는 지원하지 않습니다.

## 편집 가능한 판서 파일

판서 탭의 ‘편집 가능한 판서 파일’에서 대상 화면을 선택하고 ‘판서 파일 저장’ 또는 ‘판서 파일 열기’를 누릅니다. .minicast 파일은 현재 형식 버전 1의 UTF-8 JSON이며, 한 화면의 원래 뷰포트와 확정 객체를 저장합니다. 펜·형광펜·도형·채우기·텍스트 내용과 변형을 다시 편집할 수 있습니다. 임시 표시·UI·배경 화면·Undo/Redo 이력·모니터 ID·설정은 파일에 저장하지 않습니다. 자동 저장이나 앱 시작 시 자동 복원은 하지 않습니다.

저장은 요청 시점의 문서를 고정하고 원자적으로 파일을 교체합니다. 기존 파일 교체 확인은 네이티브 저장 창에서 처리합니다. 저장 또는 열기를 시작하면 클릭 통과로 바뀌고, 작업 중에는 판서 도구로 전환하지 않습니다. PNG 내보내기와 파일 작업의 네이티브 대화상자는 중복되지 않습니다.

열기는 선택한 한 화면의 판서를 교체합니다. 현재 판서가 있으면 취소를 기본값으로 하는 확인 창을 표시하며, 한 번의 실행취소로 이전 판서 전체를 복원합니다. 다른 모니터의 문서는 유지됩니다. 파일 내용이 현재 판서와 같으면 이력과 revision을 변경하지 않습니다. 원래 뷰포트와 대상 화면 크기가 다르면 비율을 유지해 중앙에 맞춥니다. 변환 결과가 좌표·굵기 한도를 넘으면 임의 보정 없이 거부합니다.

64MiB 파일 크기, UTF-8 인코딩, 형식 버전, 필드 목록, 객체 ID 중복, 좌표·스타일, 객체·포인트 총량을 검사합니다. 손상·알 수 없는 버전·잘못된 입력·연결 해제·읽기 실패에는 기존 문서를 변경하지 않습니다. 파일 선택·확인 중 대상 문서가 변경되면 오래된 열기 요청을 거부합니다. 취소 시에도 문서와 Undo/Redo는 그대로 유지됩니다. 승인한 디스크 쓰기가 시작되면 정상 종료는 해당 쓰기의 완료 또는 실패를 기다립니다.

빈 문서도 저장·열 수 있으며, 빈 문서로 현재 판서를 교체한 경우에도 실행취소할 수 있습니다. 모든 모니터를 묶은 세션 파일, 파일 연결을 통한 더블클릭 실행은 포함하지 않습니다. 현재 파일 형식에 이전 버전 변환기나 호환 경로는 두지 않습니다.

## 이력·취소·동기화

이동·크기 조절·회전·반전·채우기·선택 삭제·판서 파일 열기 각각 한 번을 해당 작업 전체에 대한 Undo 한 번으로 처리합니다. 클릭이나 변화 없는 조작은 이력과 Redo를 바꾸지 않습니다. 조작 중 Ctrl+Z는 진행 중 미리보기만 취소하고, Escape는 조작 모드로 돌아갑니다. 재로딩·도구 변경은 미완성 작업을 폐기합니다.

main process의 모니터별 문서와 전역 시간순 Undo/Redo가 권위 상태입니다. 편집은 기준 revision을 포함하고, 다른 편집이나 화면 재설정으로 revision이 바뀌면 오래된 요청을 그룹 단위로 거부합니다. 초기 연결·복구에는 전체 문서를, 일반 편집에는 변경분을 전달합니다. 분리된 모니터의 문서와 관련 이력은 정리합니다. 앱을 종료하면 실행 중 문서와 이력은 초기화되므로 다시 사용할 판서는 종료 전에 파일로 저장해야 합니다.

자유곡선은 점 목록, 직선·화살표는 두 끝점, 사각형·타원·텍스트는 원점과 두 축 끝점으로 저장합니다. 별도의 회전 전용 이력이나 래스터 객체를 만들지 않습니다. renderer·preload·main은 함께 빌드해야 합니다. 타원은 지우개 판정에서만 보수적인 0.125 CSS px 오차 범위로 선분화합니다.

## 검증과 범위

단위 검사는 기하·불변성·원자적 거부·전역 이력·viewport 변형·변경분 복구와 파일 형식·읽기·쓰기를 검사합니다. `rendering-smoke.ts`는 실제 Chromium에서 부분 재그리기와 전체 재그리기를 픽셀 단위로 비교합니다. 도구별 Windows 검사는 핸들·Shift 그룹 조작·취소·오래된 revision·드래그 중 재로딩을 검사합니다. `document-file-smoke.ts`는 실제 저장·열기·교체 확인 대화상자와 Undo 픽셀 복원을 검사합니다. 성공 여부는 해당 실행의 로그를 기준으로 판단합니다. 검증 워크플로는 수동 실행만 허용합니다.

실물 GPU·펜 드라이버·혼합 DPI 모니터·물리 한글 IME는 별도 검증 대상입니다. 배경 화면 캡처·자동 판서 저장·파일 더블클릭 연결은 지원하지 않습니다.


## 화이트보드·블랙보드 (0.14.0)

판서 탭의 ‘판서 배경’에서 대상 화면을 고른 뒤 ‘화면 판서’, ‘화이트보드’, ‘블랙보드’를 누릅니다. 선택한 모니터의 배경만 바꾸고 기존 객체·겹침 순서·Undo/Redo는 보존합니다. 조작 모드에서 누르면 펜 모드로 들어가며, 이미 판서 중이면 현재 도구를 유지합니다.

배경은 문서가 아니라 발표용 세션 표시입니다. Escape·조작 모드·컨트롤러 숨김에서는 배경을 숨겨 아래 프로그램을 보면서 클릭할 수 있게 합니다. 같은 세션에서 판서 도구로 돌아오면 선택한 배경이 다시 나타납니다. 일반 판서는 이전과 같이 남습니다. renderer 재로딩·오버레이 재생성에서는 배경 선택을 복원하며, 모니터 연결 해제와 앱 종료에서는 해당 선택을 폐기합니다.

배경 변경은 실행취소 이력을 만들지 않으며 진행 중 입력만 취소합니다. 이미 확정된 객체와 파일 저장 내용은 변하지 않습니다. 펜·텍스트·윤곽선 색상은 자동으로 바꾸지 않으므로 배경과 구분되는 색을 고르세요. PNG·클립보드는 계속 투명한 판서 이미지를 만들고, `.minicast` 파일에는 배경을 넣지 않습니다. 다른 파일을 열어도 현재 발표 배경은 유지합니다.

네이티브 파일·이미지 작업 또는 텍스트 편집 중에는 배경 변경을 거부하고 안내합니다. 지연된 초기 상태 응답이 더 새로운 배경 선택을 덮지 않도록 별도 상태 revision을 사용합니다. 보드별 별도 페이지나 무한 캔버스 기능은 포함하지 않습니다.


## 통합 경계 처리 (0.14.1)

파일·PNG·클립보드의 승인된 쓰기가 진행 중이면 정상 종료를 보류합니다. 성공 뒤에만 트레이·입력 훅·단축키를 정리하며, 쓰기 실패는 종료를 취소하고 현재 판서를 유지해 다시 저장할 수 있게 합니다. 자동 저장이나 운영체제 강제 종료 복구 기능은 아닙니다.

준비 단계의 저장·열기·내보내기 요청은 컨트롤러 숨김·최소화·재로딩으로 무효화합니다. 숨겼다 다시 표시해도 이전 요청을 재사용하지 않습니다. 이미 승인된 쓰기는 중간에 끊지 않습니다.

일반 판서의 CSS 크기 또는 DPR이 바뀌면 진행 중 획·도형·지우개와 pointer capture를 취소한 뒤 확정 문서를 다시 그립니다. 크기가 같은 중복 이벤트는 입력을 취소하지 않습니다.


## 미저장 판서의 정상 종료 보호 (0.14.2)

확정된 판서가 마지막으로 저장하거나 연 .minicast 내용과 다르면 정상 종료에서 ‘저장하지 않은 판서’를 확인합니다. 기본 버튼과 Enter·Escape는 ‘돌아가기’이며, ‘저장하지 않고 종료’를 명시적으로 선택해야 버립니다. 돌아간 뒤 기존 파일 저장·열기 UI로 화면별로 저장합니다. 이 대화상자 자체에는 자동 저장 기능이 없습니다.

저장 완료 전에는 저장됐다고 표시하지 않으며, 이전 시점의 저장이 끝나도 이후 편집은 미저장으로 남습니다. Undo/Redo로 저장된 내용에 정확히 돌아오면 경고를 없앱니다. PNG·클립보드·보드 배경·설정 저장은 편집 파일 저장으로 간주하지 않습니다. 빈 새 화면은 경고하지 않지만, 저장한 객체를 모두 지운 변경은 확인합니다.

모든 연결된 화면의 미저장 상태를 확인하고, 확인 도중 문서 내용이 바뀌면 이전 폐기 승인을 재사용하지 않습니다. 종료 확인 중에는 판서 단축키와 포인터를 잠시 막고 취소하면 복원합니다. 파일 선택창·화면 재구성이 진행 중이면 종료를 보류하며 중복 대화상자를 쌓지 않습니다. 승인된 실제 쓰기는 기존처럼 성공·실패를 기다립니다.

보호 대상은 현재 연결된 화면의 확정 문서입니다. 아직 배치하지 않은 텍스트 초안, 분리된 모니터의 폐기된 문서, 운영체제 강제 종료·로그아웃·프로세스 강제 종료의 복구나 자동 저장은 포함하지 않습니다.
