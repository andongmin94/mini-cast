# MiniCast

강의, 발표, 스트리밍 화면 위에 마우스·키보드 입력을 표시하고 직접 판서하는 Electron 앱입니다.

## 기능

- 커서 위치·마우스 클릭·조합키·일반 키 표시
- 펜 · 형광펜 · 요소 지우개
- 모니터별 화이트보드·블랙보드 배경 전환 (판서·Undo 유지, Escape로 배경 숨김)
- 직선 · 화살표 · 사각형 · 타원 · 도형 내부 채우기
- 한글·여러 줄 텍스트 배치와 기존 텍스트 재편집
- 객체 선택 · Shift 추가 선택 · 그룹 이동 · 크기 조절 · 회전 · 좌우/상하 반전 · 선택 삭제
- 모든 모니터에 걸친 시간순 실행 취소·다시 실행
- 레이저 포인터 · 시간이 지나면 사라지는 임시 잉크
- 대상 모니터의 확정 판서를 투명 PNG로 저장하거나 이미지 클립보드로 복사
- 작업 표시줄 영역을 포함한 다중 모니터 판서와 모드별 클릭 통과
- 표시 색상·크기·위치·지속 시간 설정, 설정 저장, 트레이, 싱글 인스턴스

판서 모드에서는 커서 하이라이트와 클릭 효과가 자동으로 숨겨지고 키 입력 표시는 유지됩니다. MiniCast 자체 판서 단축키는 키 입력 표시에 포함하지 않습니다.

판서 문서와 실행 취소 이력은 Electron 메인 프로세스가 소유합니다. 디스플레이 이벤트로 오버레이 창이 다시 만들어져도 같은 디스플레이 ID의 판서는 유지되며, 앱을 종료하면 판서 문서는 초기화됩니다. 분리된 모니터의 문서와 관련 이력은 정리하고, 장시간 세션의 포인트·실행 취소 이력에는 상한을 적용합니다.

## 판서와 편집

컨트롤러의 판서 탭에서 도구를 선택합니다. 직선·화살표는 Shift로 방향을 45도 간격에 맞추고, 사각형·타원은 정사각형·원으로 그릴 수 있습니다. 선택한 객체는 모서리 핸들로 크기를 조절하고 회전 핸들로 회전합니다. Shift는 크기 조절의 비율 유지와 회전의 15도 간격 고정에 사용합니다. 그룹 편집 한 번은 Undo 한 번으로 되돌립니다.

레이저는 궤적을 남기지 않는 빨간 포인터입니다. 사라지는 잉크는 펜을 놓은 뒤 2초 유지하고 0.7초 동안 소멸합니다. 두 도구의 임시 표시와 기존 문서 이력은 분리됩니다. 임시 표시 모드의 Ctrl+Z는 진행 중 입력만 취소하고, ‘임시 지우기’는 모든 모니터의 임시 표시만 제거합니다.

## PNG 저장·이미지 복사

판서 탭의 **판서 이미지 내보내기**에서 대상 화면을 고르고 **PNG 저장** 또는 **이미지 복사**를 누릅니다. 선택한 모니터의 확정 문서를 화면 전체 크기의 투명 PNG로 내보냅니다. 배경 화면·컨트롤러·선택 테두리·진행 중 미리보기·레이저·임시 잉크는 포함하지 않습니다.

PNG 저장은 클릭 통과 모드로 전환한 뒤 Windows 저장 대화상자를 엽니다. 저장 중 추가 편집을 해도 요청 시점의 문서를 내보내며, 내보내기는 기존 문서와 Undo/Redo를 바꾸지 않습니다. 빈 문서나 실패한 요청은 안내 메시지로 확인할 수 있습니다.

PNG는 이미지이며 다시 편집할 수 있는 판서 파일이 아닙니다. 편집 가능한 객체를 보관하려면 판서 탭의 **판서 파일 저장·열기**에서 `.minicast`를 사용합니다. 열기는 선택한 한 화면만 교체하고 한 번의 Undo로 되돌릴 수 있습니다. 자동 저장과 배경 화면 캡처는 지원하지 않습니다. 이미지 크기 제한과 세부 동작은 [판서 도구 가이드](docs/ANNOTATION-TOOLS.md)를 참고합니다.

## 판서 단축키

| 조합 | 동작 |
| --- | --- |
| `Alt+Shift+1` | 클릭 통과 모드 |
| `Alt+Shift+3` | 펜 |
| `Alt+Shift+4` | 형광펜 |
| `Alt+Shift+5` | 지우개 |
| `Alt+Shift+6` | 실행 취소 |
| `Alt+Shift+7` | 현재 커서 모니터 지우기 |
| `Esc` | 진행 중 판서 취소 후 클릭 통과 |
| `Ctrl+Z` | 실행 취소 |
| `Ctrl+Shift+Z` | 다시 실행 |

일반 판서 모드의 실행 취소·다시 실행은 모든 모니터의 작업을 시간순으로 되돌립니다. 진행 중인 제스처가 있으면 첫 실행 취소는 그 제스처만 취소합니다. 컨트롤러의 `화면지우기`는 마지막으로 판서한 모니터를 대상으로 하며, `Alt+Shift+7`은 현재 커서가 있는 모니터를 지웁니다. 임시 표시 모드에서는 앞서 설명한 임시 지우기 정책을 따릅니다.

컨트롤러 창을 닫아 숨길 때도 클릭 통과 모드로 자동 복귀하며, `Alt+Shift+1`은 전역 단축키 등록 충돌에 대비해 입력 훅에서도 비상 복귀를 처리합니다.

## 실행

Node.js 22.12 이상이 필요합니다. Node.js 24 사용을 권장합니다.

```bash
npm ci
npm run app
```

`npm run dev`는 renderer만 실행합니다. 전역 입력과 오버레이를 확인하려면 `npm run app`을 사용합니다.

## 검증

```bash
npm run typecheck
npm test
npm run lint
npm run smoke
```

## 빌드

```bash
npm run build
```

Windows 결과물은 `output/`에 생성됩니다. 현재 배포 대상은 Windows x64이며 macOS 설정은 패키징 골격만 포함합니다.
